# Hoja de Trabajo 2 - Semuc Champey

## Descripción

Este proyecto corresponde a la segunda versión de la página web sobre el destino turístico Semuc Champey. Se realizaron mejoras en la estructura HTML y se incorporó una hoja de estilos CSS para ofrecer una interfaz más atractiva, organizada y responsiva.

## Mejoras realizadas

- Se mejoró la estructura semántica utilizando etiquetas como `header`, `nav`, `main`, `section` y `footer`.
- Se agregó una hoja de estilos externa (`Estilos.css`).
- Se aplicó una paleta de colores inspirada en la naturaleza.
- Se mejoró el menú de navegación.
- Se agregaron sombras, bordes redondeados y espaciado entre secciones.
- Se mejoró la presentación de la tabla del itinerario.
- Se añadieron atributos `alt` a las imágenes para mejorar la accesibilidad.
- Se implementó un diseño responsivo mediante **Media Queries**.

## Tecnologías utilizadas

- HTML5
- CSS3
